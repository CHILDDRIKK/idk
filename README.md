📖 About
This repository contains a comprehensive guide and technical documentation for writing scripts (exploits) in Luau for the Roblox platform. Whether you are a beginner or an advanced developer, you'll find everything you need here.
✨ Features

    Deep Dive into Luau: From basic variables to advanced metamethod hooking.
    Environment API: Detailed docs on getgenv, getrawmetatable, hookfunction, etc.
    Anti-Cheat Bypass: Educational insights into how modern ACs work and how to stay undetected.
    GUI Tutorials: How to build clean and optimized user interfaces.

🚀 Getting Started

    Join our Discord to get the latest updates.
    Explore the /docs folder for step-by-step tutorials.
    Check out the Examples/ directory for ready-to-use snippets.

📖 О проекте
Этот репозиторий содержит подробное руководство и техническую документацию по написанию скриптов (читов) на языке Luau для платформы Roblox. Здесь собрано всё: от азов до продвинутого уровня.
✨ Что внутри

    Полное погружение в Luau: От простых переменных до работы с метатаблицами (metamethod hooking).
    Environment API: Описание функций эксплойтов: getgenv, getrawmetatable, hookfunction и другие.
    Обход анти-читов: Образовательный контент о работе современных защитных систем.
    Создание GUI: Гайды по разработке красивых и оптимизированных меню.
